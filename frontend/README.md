# Pigzel Frontend

Planned Next.js + TypeScript web interface for Pigzel.

## Status

Not yet implemented. The frontend will be built in Milestone 6 after the backend pipeline, schemas, and approval workflows stabilize.

## Planned Capabilities

- **Simple Mode**: Guided brief submission, concept selection, and video export.
- **Advanced Mode**: Full storyboard editing, visual bible inspection, scene-level regeneration, and provider configuration.
- **Approval Gates**: Interactive review between Creative Intelligence, Visual Planning, and Video Production stages.
